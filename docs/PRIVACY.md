# 隱私說明 Privacy

> 最後更新:2026-06-12

課程簽到牆是給課堂/活動現場互動用的工具。本文件說明蒐集了什麼、怎麼用、存多久。

## 蒐集什麼
- **學員**:你輸入的名字(可匿名的模式下可留空)、留言/問題內容、選的 emoji、按 ❤️ 的紀錄(以瀏覽器隨機 ID 記錄,非個人身分)、送出時間。
- **技術性**:為防止濫用,伺服器會「短暫」記錄來源 IP 的請求時間戳(僅用於限流,滑動視窗過後即失效)。
- 不蒐集 email、電話、帳號、精確位置,也沒有第三方追蹤/廣告。

## 怎麼用
- 名字與內容會**即時顯示在課程牆**(學員頁、投影牆、角落即時)。
- 簽到模式可由講者**匯出 CSV** 作為出席名單。
- 僅供該堂課/活動使用,不轉作其他用途、不販售。

## 存多久
- 場次資料(含學員名字與內容)在**場次建立 30 天後自動刪除**(每日排程清理)。
- 講者也可在後台**隨時手動刪除**整個場次,立即清除所有資料。
- 限流用的 IP 時間戳僅短暫存在,過了視窗即無效。

## 你的選擇
- 多數模式可**匿名**參與(留白名字)。
- 不想留下內容就不要送出;送出前畫面會提示「送出即表示同意顯示在課程牆」。

## 儲存與位置
資料存放於 Netlify Blobs(隨網站部署的內建儲存)。傳輸經 HTTPS 加密。

## 聯絡
有疑問或想提前刪除資料,請聯絡課程講者(Summer's Lab)。
